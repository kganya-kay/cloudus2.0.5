# Cloudus OS design system

## Principles

Premium, calm, thumb-first. No loud gradients. Dark mode is near-black with warm type, not cold corporate navy.

## Tokens

| Token | Light | Dark |
| --- | --- | --- |
| Background | `#f6f4f1` | `#0b0b0d` |
| Foreground | `#141414` | `#f4f1ea` |
| Accent | `#2563eb` | `#60a5fa` |
| Success | Emerald | Emerald |
| Warning | Amber | Amber |
| Danger | Rose | Rose |

Spacing is 8-point. Cards are 24px radius. Buttons are full pills with a 44px minimum hit area on mobile.

## Primitives

`src/components/os/primitives.tsx`

- Button, Card, Badge, Avatar
- PageHeader, EmptyState, ErrorState, SkeletonGrid
- OfflineBanner

Typography uses Geist. Display and titles are tight and quiet.
